# Tech Stack

## Overview

The Enspace CRM 2.0 system is a **REST API** built with the **Laravel framework**. The backend exposes JSON endpoints for the frontend application to consume, while this documentation site (Docusaurus) is maintained separately.

## Backend

| Technology | Version | Purpose |
|-----------|---------|---------|
| PHP | `^8.3` | Runtime language |
| Laravel Framework | `^13.8` | Web framework, Eloquent ORM, migrations, seeding |
| Laravel Sanctum | `^4.0` | API token authentication (`auth:sanctum`) |
| Laravel Tinker | `^3.0` | Interactive REPL for the app |

## Database

| Technology | Version | Notes |
|-----------|---------|-------|
| MySQL | `8.0` | Run via `docker-compose.yml` (Docker container) |
| phpMyAdmin | latest | Web UI for DB inspection, also in `docker-compose.yml` |

Schema is versioned through **Laravel migrations** (`database/migrations/`). Sample/reference data is loaded through **seeders** (`database/seeders/`).

## Local Development Workflow

```bash
# 1. Create env + key (first time only)
copy .env.example .env   # Windows
cp .env.example .env     # Linux / macOS
php artisan key:generate

# 2. Start MySQL + phpMyAdmin
docker compose up -d

# 3. Build the schema and load seed data
php artisan migrate:fresh --seed

# 4. Link public storage (required — meeting room images resolve via /storage/...)
php artisan storage:link

# 5. Serve the API
php artisan serve
```

:::note
`storage:link` creates the `public/storage` → `storage/app/public` symlink. Meeting room image URLs are built as `asset('storage/<path>')` (`MeetingRoomImage::url`), so this must be run or the images return `404` locally.
:::

Useful commands:

```bash
php artisan migrate            # run pending migrations
php artisan migrate:refresh    # roll back all + re-run all up() methods
php artisan db:seed            # run all seeders
php artisan db:seed --class=ServiceSeeder
php artisan test               # run the test suite
```

:::note
Real production data (the 6 real services and 54 real units) is loaded with **gitignored private commands** (`php artisan seed:services`, `php artisan seed:units`, `php artisan seed:contracts`) — see [Architecture](./architecture) for the seeding strategy.
:::

## Project Conventions

| Convention | Rule |
|-----------|------|
| Models & Controllers | PascalCase, singular (`Service`, `UnitsController`) |
| Migrations | snake_case, plural (`create_units_table`) |
| Statuses | Backed enums in `app/Enums/` — single source of truth |
| Audit columns | `created_by`, `updated_by`, `deleted_by` where tracked |
| Deletes | Soft deletes on `services` / `units`; deletion blocked on `contracts` |
