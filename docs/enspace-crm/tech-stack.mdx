# Tech Stack

## Overview

The Enspace CRM 2.0 system is a **REST API** built with the **Laravel framework**. The backend exposes JSON endpoints for the frontend application to consume, while this documentation site (Docusaurus) is maintained separately.

## Backend

| Technology | Version | Purpose |
|-----------|---------|---------|
| PHP | `^8.3` | Runtime language |
| Laravel Framework | `^13.8` | Web framework, Eloquent ORM, migrations, seeding |
| Laravel Sanctum | `^4.0` | API token authentication (`auth:sanctum`) |
| Laravel Tinker | `^3.0` | Interactive REPL for the app |

## Database

| Technology | Version | Notes |
|-----------|---------|-------|
| MySQL | `8.0` | Run via `docker-compose.yml` (Docker container) |
| phpMyAdmin | latest | Web UI for DB inspection, also in `docker-compose.yml` |

Schema is versioned through **Laravel migrations** (`database/migrations/`). Sample/reference data is loaded through **seeders** (`database/seeders/`).

## Development & QA Tooling

| Package | Purpose |
|---------|---------|
| PHPUnit | `^12` — feature + unit tests (`tests/Feature/`, `tests/Unit/`) |
| Faker PHP | `^1.23` — fake data generation in factories/tests |
| Laravel Pint | `^1.27` — code style fixer |
| Collision | `^8.6` — pretty CLI error output |
| Mockery | `^1.6` — test doubles |
| Laravel Pail | `^1.2.5` — real-time log tailing |

## Repositories

| Repo | Purpose |
|------|---------|
| `enspace-crm_2.0-server` | Laravel REST API (backend) |
| `enspace-documentation` | This Docusaurus MDX documentation site |

:::note
There is no frontend repository inside this workspace — the frontend application lives elsewhere and consumes the REST API documented here.
:::

## Local Development Workflow

Setting up the environment (installing tools, `.env`, Docker, migrations, `storage:link`) is covered in the **[Onboarding](./onboarding)** guide. This page only lists the technology stack.

## Project Conventions

| Convention | Rule |
|-----------|------|
| Models & Controllers | PascalCase, singular (`Service`, `UnitsController`) |
| Migrations | snake_case, plural (`create_units_table`) |
| Statuses | Backed enums in `app/Enums/` — single source of truth |
| Audit columns | `created_by`, `updated_by`, `deleted_by` where tracked |
| Deletes | Soft deletes on `services` / `units`; deletion blocked on `contracts` |
